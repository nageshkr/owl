# Office Work Log (OWL)

OWL is intended to be a tool to help an employee easily keep track of work and keep record of work done on a daily basis.

## Features

- Auto Import meetings from calander (Outlook, Google)
- Add task's, option to self record time
- set deadlines, priority
- auto update worklog in jira with comments
- manually add/remove hours from task
- Manage multiple projects
- Manage hourly pricing per project
- Add important notes for onself with search functionality
